# Motion Quality System

## Primary action

State each beat as:

```text
subject + intention + force + destination + feeling
```

Example:

```text
The send button commits the prompt into a fast tool-routing space with controlled urgency.
```

## Event phases

Block:

1. Setup
2. Anticipation
3. Commitment
4. Impact or passing pose
5. Brake
6. Settle

Not every beat needs a bounce. Concentrate squash, stretch, blur, and recoil around force events.

## Motion hierarchy

1. Functional interaction or product motion
2. Camera/crop
3. Typography
4. Secondary UI or imagery
5. Decorative accents

Delay secondary layers by 2-6 frames. Never let particles or glows lead the story.

## Fast pacing

Speed comes from:

- Large spacing changes after short anticipation
- Overlapping outgoing and incoming actions
- Matched edges, paths, colors, or shapes
- Short readable holds
- Asymmetric acceleration and braking
- Purposeful palette changes

Avoid constant speed, identical easing, a hard cut every second, multiple equal-priority actions, and effects that obscure the product.

## Color state machine

Define 2-5 named states tied to meaning:

```text
brand-neutral -> interaction-blue -> execution-magenta -> result-orange -> logo-neutral
```

Trigger transitions from an authentic event: cursor, light source, product surface, screen edge, or content movement.

## Continuity

Preserve position and velocity unless the cut is an intentional impact. Let a visual token transform across scenes:

- Cursor -> reasoning path -> chart axis -> logo stripe
- Light streak -> highlight -> CTA underline
- Product edge -> mask -> card boundary -> final frame

## Readability

- One hero subject per beat
- Deliberate minimum copy hold
- Clear silhouette and hierarchy
- Negative space around the official logo
- No stretched or cropped logos

## Determinism

For every channel:

```text
value = f(frame, fps, inputs, constants)
```

Use stable seeds. Never accumulate state frame to frame.
