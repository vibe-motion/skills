# Source and redistribution boundaries

The TypeScript components in this bundled library were independently implemented with React and
Remotion and are distributed as part of `remotion-code-motion-explainer`.

General motion patterns were studied from public material including:

- Remotion documentation and public template demonstrations;
- `reactvideoeditor/remotion-templates` (MIT);
- `neutral-Stage/remotion-captioneer` (MIT);
- `maxtron777/remotion-business-templates` (MIT);
- `av/remotion-bits` (MIT);
- `Vincentwei1021/video-shotcraft` (Apache-2.0).

Some public demonstrations or repositories did not provide a clear redistribution license. Their
source code, videos, project files, logos, audio, fonts, and branded artwork are not included.
Only general ideas, independently implemented layouts, and brand-neutral motion systems are
distributed here.

The `ui-ae-neon-replica-plan.json` file retains timing and geometry research metadata, but the
reference video is intentionally excluded. Replace `reference-not-redistributed.mp4` with a
reference you own or are licensed to use when running a reconstruction study.

Preview and showcase videos included in this Skill were rendered from the independently implemented
components or original project code. Do not infer rights to third-party brands merely because a
generic interaction pattern appears in this library.
